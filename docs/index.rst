Welcome to TargetedRicciCurvature's documentation!
==================================================

This package is a product of the work done by Bhaskar DasGupta's `Creative Algorithms lab <https://bdasgup.github.io/professional/algo-lab.html>` In this package you can find the implementations of Ollivier Ricci Curvature for graphs in many forms. This includes directed vs undirected, weighted vs unweighted, and simple vs hypergraphs. We also have this program set up to calculate distance between two graphs based on a few heuristices.

One of the better uses for this project at the moment is being able to find the curvature for a graph as a whole either sequentially or in a parallel fashion.
