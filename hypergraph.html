floyd_warshall() → list[list][source]#
Use the Floyd-Warshall algorithm to find the shortest distances between

each pair of vertices. Right now, if you cannot get from one node to another, the distance will be the maximum value + 1. This will be relevant in the case of directed, not strongly connected graphs.

Return list[list]:

a matrix with the shortest distances, that will be ordered by self.node_index
